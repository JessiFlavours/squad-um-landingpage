# squad-um-landingpage

# 📚 Trabalho Acadêmico - DEMODAY SQUAD 1

> Landing page desenvolvida para a apresentação do projeto do nosso grupo.

---

## 🚀 Sobre o Projeto
Depois dos conhecimentos adquiridos com o curso de DevOps do Avanti, disponibilizado pelo Instituto Atlântico, estamos colocando em prática o que aprendemos e utilizando boas práticas de DevOps.

## 🛠️ Tecnologias Utilizadas
O site foi construído de forma leve e rápida utilizando as seguintes tecnologias:
- **HTML5** - Estruturação de conteúdo.
- **Tailwind CSS** - Estilização moderna e responsiva diretamente via CDN.

## 💻 Como Executar o Projeto Localmente

Se você deseja visualizar o site no seu próprio computador, siga os passos abaixo:

1. Baixe o código deste repositório ou clone o projeto:
   ```bash
   git clone https://github.com[SEU-USUARIO]/[NOME-DO-REPOSITORIO].git
   ```
2. Navegue até a pasta do projeto.
3. Dê dois cliques no arquivo `index.html` para abri-lo diretamente no seu navegador.
